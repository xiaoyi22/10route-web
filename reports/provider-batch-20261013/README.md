# 供应商与账号批量操作

2026-10-13，分支 `main`。供应商总览和单个供应商的账号列表均支持勾选、全选、半选提示、取消选择、批量测试及批量绑定代理。

## 操作规则

- 供应商总览全选当前筛选中有账号的供应商，批量操作作用于所选供应商下的全部账号。空供应商不可勾选。
- 账号列表全选当前筛选中的账号。改变搜索、正常连接筛选或切换供应商后，清空勾选。
- 批量测试逐个调用现有账号测试接口，显示处理进度及成功、失败、跳过数量；停用账号不测试。支持查看逐项结果和仅重试失败账号。
- 批量代理配置支持绑定代理池、连接专用代理、继承全局规则。保存包含所选的停用账号，不改变账号启用状态、优先级、密钥或其他配置。
- 部分代理配置失败时，显示逐项结果并保留窗口；“重试失败项”只提交失败账号。切换代理配置选项后，重新应用到原选中账号范围。
- 每个账号独立保存，批量操作不提供数据库事务；成功项保留，失败项可单独重试。
- 复用 `POST /api/providers/:id/test` 与 `PUT /api/providers/:id`，没有新增后端接口或依赖。
