## 已恢复与修复

| 功能 | 已核实问题 | 本次修改与证据 |
| --- | --- | --- |
| 下游分发 | 路由、存储和调用闸门缺失 | 恢复保存/读取、管理目录、公共模型过滤、各入口限制。聊天、Messages、Responses、图像、语音、搜索、视频 7 个入口拒绝为 404 JSON，测试上游新增 POST 为 0 |
| 余额与配额 | 余额路由、适配模块、偏好写入缺失 | 恢复路由、适配、数据库导出及偏好持久化。HTTP 与浏览器真实保存回读通过；没有用假余额证明真实供应商余额正确 |
| 兼容节点强制流式 | 节点及模型配置失效 | 恢复配置链路，与新版注册表共同生效。上游实测 `stream:true`，下游同步收到 200 JSON 和 `AUDIT_OK` |
| 自定义模型开关 | 禁用模型可能被上游目录带回 | 保留本地禁用状态优先级；禁用后管理目录不再出现该模型，HTTP 断言通过 |
| 密码二次验证 | 连续错误后的失败计数与锁定被移除 | 恢复锁定及成功清零；原有用例通过，没有向生产发送错误密码序列 |
| SSE 与协议转换 | 多行帧、跨字节中文/表情、Claude/多 choice/Responses 内容、工具或错误处理回退 | 恢复解析与聚合；上游错误返回 502 JSON 并保留本次请求的错误代码；保留新版截断标记、DONE 完成、看门狗、模型身份与 Responses 连续性 |
| 流结束与用量 | 尾用量被估算覆盖、取消时丢用量、误判 DONE | 恢复真实用量优先、取消结算与单次完成；按完整事件识别 DONE，不匹配正文字符串；针对性流测试通过 |
| 速度统计 | 历史和详情口径含旧回退，快流被阈值压低 | 统一节点/模型、历史/详情的持续时间选择；显式流式缺可靠首包时间时不伪造速度，非流式使用总时长；保留高于 300 token/s 的实测速度 |
| Antigravity | 专用隔离、跨账号预算、刷新去重与配额窗口保护缺失 | 恢复隔离持久化、明确解除、请求停止状态与统一预算，保留新版 reauth/凭据持久化；用假账号与可控 403/429 验证，没有操作真实账号 |
| 工具调用元数据 | Responses 的 Chat 风格输入丢失工具调用和结果 ID，会导致严格上游拒绝 | 保留两种调用形状及 ID，复用已有缺失结果补全逻辑；3 项原有用例通过，编译后 HTTP 实测调用 ID 和结果 ID 均到达 Chat 上游 |

工具元数据问题在修复前工作区实测失败；升级前快照对应实现也缺少保留逻辑，不能只凭历史基线标为通过就断言全部由本次升级造成。

模型检测没有整块丢失：线上 `/api/iq-monitor` 返回 200 JSON，运行产物有检测和 tick 路由。独立前端已有显式选择实现及相应用例。旧 `modelSelection.js` 缺失，不等于当前页面没有该功能。既有未跟踪检测源码已备份并随原始定制源码包保留。
