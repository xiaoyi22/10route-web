# 请求日志端点详情

列表继续显示客户端请求网关的入口端点。悬浮、键盘聚焦或触屏点击端点可查看双行卡片：入口端点与出口端点。卡片适配浅色、深色和窄屏，按 Escape 或点击外部关闭；详情窗口和 CSV 导出保留两个独立字段。

## 数据口径

- 入口使用后端现有字段 endpoint，不改变历史字段含义。
- 出口端点表示网关实际发出请求的 API 路径，使用后端字段 upstreamEndpoint，只记录实际执行器返回 URL 的 pathname；不是代理出口 IP 或出口节点。
- 初次请求和鉴权刷新后的重试均采集实际发送路径，不按供应商名称、类型或当前 baseUrl 推断。
- 不持久化 URL 中的鉴权信息、查询参数或 fragment。无有效 HTTP(S) URL 时不制造上游路径。
- 历史记录未保存出口端点时，卡片和详情显示“未记录”，CSV 留空；不回填猜测值。

## 验证

- node tests/endpoint-tooltip-browser.mjs：4338 隔离演示入口；覆盖不同入站/出站组合、历史缺失值、长路径、悬浮、键盘、触屏、详情和导出。
- node tests/endpoint-tooltip-live-browser.mjs：4317 真实入口；只读核对 WindHub 日志，不触发上游模型调用。
- 后端测试覆盖实际执行 URL、鉴权刷新重试 URL、脱敏、流式/非流式持久化及 API 返回。
