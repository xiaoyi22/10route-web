# 能力适配与语音合成

## 设置入口

- `/dashboard/settings?tab=vision`：系统设置 → 默认识图模型。包含默认识图模型和音频输入兜底，支持启停、顺序回退、轮询、添加、移除及调整模型顺序；不再放在组合模型页。
- `/dashboard/media-providers/tts`：语音供应商、账号、模型、音色、试听与音频下载。
- `/dashboard/media-providers/tts/:provider`：供应商直达链接，沿用原版地址结构。

能力适配沿用 `settings.capacityAdapter`。保存前重新读取配置，保留其他能力池和未知字段；当前能力池被其他操作修改时拒绝覆盖。空模型池保持为空，启用时由后端决定默认模型，不在前端写死兜底模型。

默认识图模型用于原请求模型不支持图片时的能力补齐，不强制替换已经支持图片的原模型；语音合成仍是独立入口。

TTS 账号沿用 `/api/providers` 的新增、修改、启停和删除接口，不新增账号库。网关调用密钥只在内存中用于请求，不写本地存储，也不输出到日志或示例代码。音色列表调用原有 `/api/media-providers/tts/*/voices`；生成调用 `/api/v1/audio/speech?response_format=json`，解码后用对象 URL 播放和下载，切换页面、重新生成时释放对象 URL。

`src/api/tts-catalog.json` 是 2026-10-15 从原网关注册表、`ttsModels.js` 与 `ttsProviders.js` 导出的 24 个 TTS 供应商模型和音色快照，与现有供应商名称、别名静态目录采用相同分发方式。升级后端模型目录时应同步核对该快照。

## 权限与分发

语音合成 POST 仅在管理模式开放。请求仍经同源代理、登录校验和真实网关 API Key 认证。上游语音错误不清除管理会话。

TTS 同样遵守“下游分发”白名单。未开放的完整模型/音色路由会显示未发布并禁用试听；“发布当前路由”需要显式确认，只合并该路由，不切换全局分发模式、不删除已有模型。加载页面不会修改生产白名单或适配器配置。
