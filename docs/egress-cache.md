# 代理出口自动检测与缓存

代理控制的“节点与出口”页会自动检测支持的 7890、7891、7892 入口。检测仅查询出口 IP / 位置，不切换节点，不执行 LLM 或 Mem0 健康检查。只读访问不会发起主动检测。

## 缓存与更新

- 每个结果绑定入口端口、代理组和完整的当前节点链，有效期为 5 分钟。
- 结果保存在当前浏览器标签页的 sessionStorage 中，切换路由、内部页签或刷新页面会恢复缓存。退出登录、登录失效会清除缓存；关闭浏览器标签页不保证保留。
- 页面可见时，过期结果自动更新；每 30 秒只读同步代理组状态，以识别外部自动切换节点。节点链改变时，仅对应入口重新检测，不展示旧节点的 IP。
- 同一节点的检测请求合并，切页不取消已发出的检测，完成后仍写入缓存。服务端也按端口和节点标识合并同节点检测，不同标识的请求依次执行。
- 同一节点更新失败时保留上次有效结果和检测时间，并提示失败。自动重试间隔为 5、10、20、40、60 秒，随后保持 60 秒；手动检测可立即重试。
- 标签页隐藏或离线时不发起新检测；恢复可见或联网后继续检查。已发出的请求允许完成。
- 浏览器存储被禁用时降级为内存缓存；刷新页面后可能重新检测。

## 接口兼容

`GET /api/hermes/egress-ip?port=7891&binding=...` 仅返回匹配节点标识的服务器缓存；没有匹配缓存时返回空检测时间。`POST /api/hermes/egress-ip` 支持可选字符串 `binding`，响应带有 `cache_binding`。不传节点标识的旧调用保持可用。

## 验证

- `node --test tests/egress-cache.test.mjs tests/hermes.test.mjs tests/client.test.mjs`：缓存、过期、退避、旧请求污染防护、并发和登录边界。
- `node tests/egress-browser.mjs`：隔离演示环境 4318，模拟接口；验证自动检测、切页/刷新恢复、手动与外部节点变化、失败保留、隐藏暂停和主题/移动端布局。
- `node tests/hermes-browser.mjs`：独立演示网关与 Hermes，验证节点选择、订阅、看护及手动健康检查边界。真实适配器检查需显式传入 `--live` 和独立服务端凭据，不使用映射盘。
- `node tests/egress-live-browser.mjs`：本地真实入口 4317；凭据读取仓库外私有文件。仅允许出口探测，不修改真实节点、订阅或业务数据。设置 `PREVIEW_URL` 可指定验收入口。
