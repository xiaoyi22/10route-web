# 模型测试修改与验收

已随模型检测修复发布生产，入口为 `http://192.168.11.150:4317`，前端版本为 `20261014-144550`。后端保持 v1.4.0。

- 模型目录及供应商模型行新增“测试”，新增和编辑模型窗口新增“保存并测试”，保留普通保存。
- 使用现有 `POST /api/models/test`，发送完整供应商路由 ID 与 `kind: llm`；自定义供应商使用目录中的前缀，内置供应商编辑保留原路由 ID。
- 单独显示未测试、测试中、调用成功、调用失败。详情显示耗时、时间、HTTP 状态、后端说明及原始错误；明确结果为本次网关路由调用，多账号时由网关选取账号。
- 普通保存不测试，保存失败不测试；停用模型、没有启用账号及非文本自定义模型禁用测试。测试中禁止重复操作，客户端请求超时为 25 秒。本次结果保存在页面内存，刷新页面清除。
- 后端文本探测仍使用既有 15 秒超时；超时代表本次测试未通过，不能单凭超时判定模型 ID 填错。
