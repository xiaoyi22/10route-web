# Qoder / WorkBuddy 模型积分与免费状态补齐计划

本轮只做调查和方案，尚未修改业务代码或发布服务。

## 已核实的现状

- 新前端位于 `E:/10reoute-web`，分支 `main`；现有工作区包含其他未提交改动，实施时只修改本需求涉及的内容。
- 原网关位于 KN10 `/home/meet/10router`，当前分支 `upgrade-v1.4.0-run`；现有部署脚本要求 x86-64，本需求属于 Web 展示与接口元数据补齐。
- 真实入口为 `http://192.168.11.150:4317`。认证状态、健康检查、登录、模型目录和供应商列表均实测 HTTP 200；健康接口返回 `driver: better-sqlite3`，认证启用密码登录。
- 原版 `ModelRow.js` 使用 `rateMultiplier` 显示积分消耗倍率，结合 `nightFree`、`promoFreeUntil`、`promotion` 展示免费或优惠状态。倍率不是每次请求固定扣除的积分数。
- WorkBuddy 对应 `codebuddy-cn` / `codebuddy-intl`，注册表已有逐模型倍率。例如国内版 `hy3` 为 0，`glm-5.3` 为 0.79，`hy4-preview` 为 0.29 且声明 23:00–08:00 免费窗口；国际版同名模型可能规则不同，不能跨地区复用。
- 原网关 `src/shared/constants/models.js` 构造 `AI_MODELS` 时只保留供应商、模型 ID 和名称。因此 `/api/models` 没有带出积分信息；真实返回的 52 个目标供应商模型均未包含这些字段。
- 新前端 `src/api/data.js` 的 `modelCatalog()` 再次只挑选名称、供应商、能力等字段，`ModelsPage` 也没有对应展示。
- Qoder 的 `GET /api/providers/{connectionId}/models` 已返回当前 `rateMultiplier` 和 `promotion`。真实 Qoder 账号接口 HTTP 200，返回 15 个模型；当次 Auto 为 0.5×，Ultimate 为 2×，后者附带 22:00–08:00（Asia/Singapore）错峰 2 折规则，查询时未生效。这些数字是查询快照，不写死在前端。
- 当次没有已启用的 Qoder 国内版账号，其真实账号结果仍待验收。

## 建议实施方案

1. **补齐数据链路。** 原网关在 `/api/models` 的逐模型映射中，从现有注册表明确带出 `rateMultiplier`、`nightFree`、`promoFreeUntil`、`promotion`，不改路由选择或计费逻辑。新前端保留这些字段；Qoder 再读取已有账号模型接口，以账号实时目录覆盖同一地区、同一模型的价格字段。无需新增接口或依赖，也不把注册表整份复制到新前端。
2. **补齐两处页面。** 模型总目录和供应商详情共用 `ModelsPage`，在模型名称附近显示“积分倍率 0.79×”“免费”“当前时段免费”或“限时免费”等中文标记。优惠说明展示原倍率、折扣、时间段、时区和截止时间（仅展示接口确实提供的内容）。Qoder 保留所选账号和查询时间，多账号明确数据来自哪个账号；路由可能选择其他账号时，不把单账号价格当作全部账号的保证。
3. **处理时间与失败。** WorkBuddy 按各地区注册表规则判断免费窗口，国内规则明确使用北京时间；限时活动使用截止时间。Qoder 的当前倍率以服务端返回值为准，跨优惠边界重新读取目录，不再次给已经折扣的倍率乘折扣。页面恢复可见、手动刷新和活动边界均刷新相关状态；价格过期或读取失败时展示“积分信息未更新”及查询时间，不继续断言“当前免费”。没有有效账号、没有价格字段或停用模型缺少元数据时显示“未提供积分信息”。0 与未知值必须区分。

建议显示“免费额度”说明：免费标记表示当前价格规则不消耗积分，账号权限、免费额度和上游限流仍以实际调用结果为准。订阅权益、余额和实际请求扣费继续使用各自的数据来源。

## 验收标准

- 两处模型列表都显示同一规则，国内与国际供应商、模型别名及自定义模型不会串价。
- 覆盖倍率为 0、正数、字段缺失、限时活动结束、跨午夜免费窗口、活动开始及结束边界、非北京时间浏览器、多账号、目录失败及过期状态。
- Qoder 已返回的折后倍率不重复折扣，非零优惠不会显示为免费；活动结束后无需重新打开页面即可更新状态。
- 新前端运行 `npm.cmd test`、`npm.cmd run build`，检查桌面与手机布局、深浅主题及浏览器未捕获异常；后端运行针对接口字段的测试和原仓库回归门禁。
- 使用真实网关只读接口核对模型倍率及页面标记，记录 HTTP 状态码和断言。当前真实账号未覆盖的地区明确列为未验收，不用演示数据替代。
- 本需求可通过目录读取验收，不需要发送消耗积分的推理请求。上线与服务重启仍需用户单独确认。
