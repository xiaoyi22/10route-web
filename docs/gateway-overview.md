# 网关概览与独立系统信息页面

系统信息独立位于侧栏「监控 → 系统信息」（`/dashboard/system`），页面实现为 `src/pages/SystemPage.jsx`。概览仅显示网关业务摘要，不显示或轮询主机指标；系统页不读取业务用量与供应商接口，离开系统页即停止系统采集。

## 页面与数据口径

- 概览使用独立的 `src/pages/OverviewPage.jsx`，详细 Token 表格继续保留在用量统计页。
- 周期请求量、Token、费用、热门模型和供应商分布来自真实 `/api/usage/stats`；Token 趋势来自 `/api/usage/chart`。
- 请求趋势使用统计接口的 `last10Minutes`，每个桶代表一分钟，从最早到当前分钟。它不受周期筛选影响。当前历史图表接口没有请求计数字段，页面不通过 Token 数或样本日志推算历史请求趋势。
- 在途数量优先累加 `activeRequests[].count`，仅在明细未提供时回退到 `pending.byModel`，不重复累加账号计数，也不将其称作排队长度。
- 账号启用是配置状态，异常账号是已启用账号的历史测试/错误记录；它们都不代表实时连通性。最近失败请求也不是整个周期的失败总量。
- 暂不展示成功率、平均延迟和 P95，避免用有限的最近请求样本代替完整聚合。

## 近期吞吐

概览核心指标下方显示 RPM、TPM 及输入/输出 TPM。复用同一统计请求中的 `last10Minutes`，取最后六个分钟桶中的前五个（`slice(-6, -1)`），排除未结束的当前分钟；显示「最近 5 个完整分钟平均」，不受今日、7 天等统计周期筛选影响。

- RPM = 五个完整分钟的 requests 合计 ÷ 5。
- 输入/输出 TPM = 同一窗口的 promptTokens / completionTokens 各自合计 ÷ 5。
- 总 TPM = 输入与输出 Token 合计 ÷ 5，不额外累加缓存 Token。
- 有效计数为零时显示 0，低吞吐保留小数。窗口不足、缺失或无效计数显示未知；输入或输出缺失时总 TPM 也保持未知，不影响仍有效的 RPM。
- 指标代表后端已记录调用的分钟平均值，不代表瞬时并发、模型生成 TPS 或上游限流额度。复用概览每 10 秒更新的统计响应，不增加接口请求；系统信息页不展示该摘要。

## 只读主机接口

`GET /api/system/info` 在开发、预览和生产 HTTP 服务中均由服务端处理。每次请求都先将当前 Cookie 转发给真实网关的 `/api/auth/status` 校验登录，未经登录返回 401，写方法返回 405；结果缓存 10 秒，并合并并发采集。采集失败返回 503，不把旧缓存当成新的健康结果。

KN10 上前端服务与网关同机运行、后端为回环地址时，自动在 Linux 本地采集，无须新增常驻服务或修改 10router 后端。远程网关且未配置采集来源时返回不可用，不回退采集预览电脑。

Windows 本地预览使用私有 `.env` 配置：

~~~dotenv
TENROUTER_SYSTEM_SSH_TARGET=meet@192.168.11.150
TENROUTER_SYSTEM_SSH_IDENTITY=
~~~

留空私钥路径时沿用当前用户的 SSH 身份配置；也可指定仓库外私钥路径。要求非交互 SSH 可用、主机已经通过 known_hosts 校验，以及 KN10 有 Node.js。SSH 只执行固定的只读采集脚本，通过标准输入传入代码，不上传文件、不执行用户请求中的命令，也不修改服务状态。私钥和 SSH 配置不进入浏览器产物。

## 指标范围

- CPU 使用率来自前后两次系统计数差值，返回实际采样时长；系统负载分别为 1/5/15 分钟负载，不是百分比。
- 内存已用量为 MemTotal − MemAvailable，Swap 按 SwapTotal/SwapFree 计算；未启用 Swap 时不伪造使用率。
- 磁盘使用量只表示根文件系统 `/`；可用容量按非特权用户可用块数计算，因此不必等于总容量减已用容量。
- 主机名、发行版、内核、架构、运行时间指 Linux 采集环境；发现容器标记时标注容器范围，虚拟机数据也不表示物理宿主机。
- 网关服务来自用户级 `10router.service` 的只读状态查询；RSS 是 systemd 主进程的驻留内存，不是服务全部子进程之和。服务状态不可读时只影响这一字段。
- 无数据保持未知，不显示假零；采集失败保留上次数据并明确标注过期。

## 刷新与验证

概览按资源分级更新：统计 10 秒，Token 图表与健康状态 30 秒，账号配置 60 秒，供应商目录 120 秒。独立系统页仍每 10 秒采集，不与概览混用。轮询从上次请求完成后计时，同一资源不会重叠加载；自动、手动、可见性与网络恢复事件使用同一调度器。重新开启自动更新或返回页面时只读取已到期资源，仍新鲜的配置数据不重复查询。

“当前在途”及“正在处理”使用独立 SSE 连接读取 activeRequests / pending.byModel；推送的累计用量、费用与模型分布不覆盖所选周期的统计。首次连接 15 秒内未收到有效在途数据，或推送格式、连接异常时关闭旧连接，按 5、10、20、30 秒间隔重连。后端在空闲时每 25 秒发送注释心跳，原生 EventSource 不会触发 message；收到首个有效事件后不以消息间隔判断断线，避免空闲误重连。在途数据选择实时快照与 10 秒统计响应中较新的一个，避免静默连接的旧快照覆盖新统计，并明确显示连接状态。未知或无效计数不能当作零。离开页面、隐藏页面或暂停自动更新时关闭实时连接。

统计与图表后台更新时保留上次成功数据。请求 12 秒超时，失败后按资源间隔指数退避，最长 120 秒，成功后恢复正常间隔；手动重试不受退避等待限制。错误、离线、暂停和后台更新状态分别提示，旧数据不会被当作新的成功响应。隐藏页面暂停轮询并取消在途请求；断网时不发送请求，显式手动刷新可等待页面可见及网络恢复后执行。首次加载和切换统计周期即使暂停自动更新仍读取一次，不允许上一周期的迟到响应覆盖新周期。

概览自动更新偏好使用既有 Zustand 持久化存储，刷新页面后保留暂停状态。用户显式手动刷新仍可重新读取全部资源，切换周期只重新读取统计与图表，不刷新账号或重建实时连接。

~~~powershell
npm test
npm run build
node tests/overview-live-browser.mjs
node tests/overview-refresh-browser.mjs
node tests/system-live-browser.mjs
~~~

真实浏览器验收从用户私有凭据文件读取密码，支持 `TENROUTER_TEST_LOGIN_ENV` 与 `PREVIEW_URL`；除登录外不写真实业务配置。连接故障仅在浏览器中模拟 HTTP 503；业务和系统数据验收使用真实响应。截图、脱敏系统摘要和验收记录存于用户目录下 `.codex/tmp/overview` 与 `.codex/tmp/system-info`。

发布脚本会携带 `system-bridge.mjs` 和 `system-info.mjs`。本轮仅更新源码及本地入口，不自动执行生产发布、提交或重启 KN10 网关。
