# 模型检测近期统计

## 统计口径

模型状态页的汇总卡片显示匹配模型数量、近30次通过、近30次异常和近期检测通过率。“通过/异常”统计检测记录次数，不再统计最新结果通过或异常的模型个数。

- 统计范围跟随检测类型、供应商、搜索和已配置/全部模型范围；对匹配模型的后台记录按时间合并，选最新30条。只有10条时按实际10条统计，不补齐虚构记录。
- 通过包含可用和全部答对；异常包含答错、限流、超时和接口故障。未评分、等待中或未知结果不算异常，也不计入通过率的分母。
- 检测通过率为通过次数除以通过与异常次数之和；完全没有已判定结果显示横线，有结果但全部失败显示0.0%。它不是模型答题正确率，题库正确率仍在模型行单独展示。
- 无效时间戳的记录不参加窗口排序和计数；无检测类型的旧记录沿用IQ类型约定。
- 分页不改变汇总范围；切换供应商不会混合其他供应商的同名模型。检测类型不混算。
- 表格仍显示每个模型的最新状态和其独立最近30轮记录。成功恢复不会清除窗口内的历史异常；仅当异常记录移出30条窗口时才不再计入。
- 本页单次测试沿用原有行为，仅更新当前页最新状态；未写入后台历史的单次结果不参与汇总，也不在浏览器刷新后凭空累计。
- 自动刷新仍每15秒只读重取后台结果，汇总不启动付费检测、不修改自动检测配置。读取失败保留上次有效数据并显示错误提示。

## 验证

- tests/monitor.test.mjs：近30条窗口、供应商与检测类型隔离、未知/未评分和异常恢复。
- tests/monitor-summary-browser.mjs：隔离演示数据复现25次通过和5次异常，验证自动刷新、恢复、筛选、分页、单次测试边界和深浅主题/手机布局。
- tests/monitor-browser.mjs：既有配置、单次检测和详情浏览回归。
- tests/monitor-summary-live-browser.mjs：本地真实入口4317，只读比较实际IQ后台记录、刷新和重新进入页面后的卡片，不触发模型测试或配置写入。
